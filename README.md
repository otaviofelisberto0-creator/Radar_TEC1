## Fluxo operacional

1. Abra **Página Auxiliar**.
2. Carregue o CSV.
3. Confirme a competência `2026-07`.
4. Converta o CSV para um único JSON mensal.
5. Baixe `tec1-26-07.json`.
6. Use o botão de acesso ao GitHub e publique o arquivo no Release `TEC1-26-07`.
7. Abra o GitHub Pages. O dashboard lê `dados/manifest.json`, usa `item.url`, carrega o asset mensal e atualiza as análises.

O JSON mensal contém `metadata`, `dados`, `tecnicos`, `operacional` e `historicoMensal`.
